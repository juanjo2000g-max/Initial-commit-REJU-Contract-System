# SICHAR OS · Pragmos

Transformación digital de SICHAR, importador y distribuidor de acabados para la construcción
(Cali, Colombia): de la consultoría estratégica a una plataforma funcional.

| Carpeta | Contenido |
|---|---|
| [`sichar-os/`](sichar-os/) | Plataforma web (React + TypeScript): Vitrina pública, CRM, cotizador, costos de importación, canal y semáforo, Mesa de Asesoría, contenido, automatizaciones y portal de distribuidores. |
| [`entrega-final/`](entrega-final/) | Demo en un solo HTML (funciona sin internet), guion de la presentación, propuesta de Pragmos y correos para la gerencia. |
| [`consultoria-sichar/`](consultoria-sichar/) | Informe de Consultoría Estratégica (Proyecto EA) en LaTeX y PDF. |

## Arranque rápido

```bash
cd sichar-os
npm install
npm run dev
```

Los datos de la plataforma son de demostración. Ver [`sichar-os/README.md`](sichar-os/README.md).
